# Tiferet agent skills

Canonical, auto-discovered skills for this repository. They live here so Warp and other agents load them without a copy step.

Human process law remains in [`docs/collab/`](../../docs/collab/process.md). Every skill follows [`docs/collab/agents/SKILL_TEMPLATE.md`](../../docs/collab/agents/SKILL_TEMPLATE.md).

Copying into `~/.agents/skills/` is optional (global convenience). If you do, drop stale `tiferet-*` copies first or they will shadow this directory.

See [CONTRIBUTING.md](../../CONTRIBUTING.md) → Working with AI Agents for the inventory.
